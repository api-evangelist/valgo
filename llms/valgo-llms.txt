# Valgo

> Valgo is a public benefit corporation building the risk quantification layer for physical AI. It builds probabilistic models of routes, tasks, and environments to produce the simulated loss estimates insurers need to price coverage for autonomous trucks, robotaxis, and robots. Y Combinator W26, backed by Floodgate and Menlo Ventures. Its first public API is the Human Crash Baselines API - human-driver crash-rate baselines by region, route, and filter.

## APIs

- [Human Crash Baselines API docs](https://docs.humanbaselines.com): Typed access to human-driver crash-rate baselines; /v1 REST surface, X-API-Key auth
- [OpenAPI (public, no key needed)](https://humanbaselines.com/openapi.json): OpenAPI 3.1 for every endpoint, filter, allowed value, and default
- [Agent primer](https://humanbaselines.com/claude): Provider-published markdown that primes a coding agent to use the API
- [Web tool](https://humanbaselines.com/): Interactive baselines tool; URL query params mirror the API's filter ids
- [Python client (PyPI)](https://pypi.org/project/humanbaselines/): pip install humanbaselines - typed models generated from the server's OpenAPI
- [GitHub: valgorithmic/humanbaselines](https://github.com/valgorithmic/humanbaselines): Apache-2.0 client source
